# خبرم کن (Khabar) — افزونه اعلان موجودی و قیمت ووکامرس

افزونه وردپرس/ووکامرس برای اطلاع‌رسانی هوشمند **موجود شدن دقیق یک تنوع محصول**، **کاهش/افزایش/تغییر قیمت** و **قوانین ترکیبی**؛ با پیامک (کاوه‌نگار، ملی پیامک، IPPanel/فراز، SMS.ir، وب‌سرویس دلخواه)، ایمیل، اعلان داخل سایت، پوش نوتیفیکیشن و واتساپ.

- نیازمندی‌ها: وردپرس ۶+، ووکامرس ۶+، PHP ۷.۴+ (برای پوش: OpenSSL و HTTPS)
- سازگار با HPOS، قالب‌های کلاسیک و قالب‌های بلوکی (مثل Twenty Twenty-Five)

## نصب

1. پوشه افزونه را در `wp-content/plugins/khabar` قرار دهید و فعال کنید.
2. از منوی **خبرم کن ← تنظیمات** کانال‌ها (مثلاً سامانه پیامک) را تنظیم کنید و از بخش «ارسال آزمایشی» تست بگیرید.
3. دکمه به‌صورت خودکار در صفحه محصول ظاهر می‌شود (یا از شورت‌کد `[khabar]` استفاده کنید).

با فعال‌سازی، ۴ جدول (`khabar_subscriptions`، `khabar_log`، `khabar_notifications`، `khabar_push`)، برگه «خبرم کن‌های من» و آیتم «خبرم کن‌های من» در حساب کاربری ووکامرس ساخته می‌شود.

## پوشش PRD

| # | قابلیت PRD | پیاده‌سازی |
|---|---|---|
| 1 | اعلان موجود شدن دقیق یک تنوع | اشتراک روی `variation_id` دقیق یا روی ترکیبی از ویژگی‌ها؛ موجود شدن آبی/۴۱ برای منتظر آبی/۴۲ اعلانی نمی‌فرستد |
| 2 | انتخاب ویژگی‌های مورد انتظار | فرم مودال با انتخاب هر ویژگی ووکامرس (یا «هر کدام»)؛ انتخاب فعلی صفحه محصول پیش‌فرض می‌شود |
| 3 | دکمه هوشمند | فقط برای محصول/تنوع ناموجود نمایش داده می‌شود؛ گزینه‌های ناموجود در لیست تنوع‌ها برچسب «ناموجود 🔔» می‌گیرند |
| 4 | کاهش قیمت | قیمت هدف (با پشتیبانی ارقام فارسی و جداکننده) |
| 5 | افزایش قیمت | آستانه «اگر بیشتر از … شد» |
| 6 | تغییر قیمت هر تنوع | اعلان تکرارشونده فقط برای همان تنوع، با فاصله حداقلی (cooldown) |
| 7 | چند روش ارسال | پیامک (۵ درگاه + حالت متنی/پترن)، ایمیل، داخل سایت، پوش (VAPID)، واتساپ (Cloud API یا وب‌سرویس) |
| 8 | لیست علاقه‌مندی هوشمند | «خبرم کن‌های من» در حساب کاربری + لینک مدیریت برای مهمان‌ها |
| 9 | ثبت بدون عضویت | فقط موبایل یا ایمیل (قابل تنظیم: یکی، هر دو، فقط موبایل، فقط ایمیل) |
| 10 | جلوگیری از اعلان تکراری | اشتراک پس از ارسال «اطلاع داده شد» می‌شود؛ درخواست تکراری با درخواست قبلی ادغام می‌شود |
| 11 | اعلان تعداد محدود | وقتی موجودی ≤ آستانه است قالب «فقط {stock} عدد…» ارسال می‌شود |
| 12 | رزرو زودتر از دیگران | پنجره خرید اختصاصی (مثلاً ۳۰ دقیقه)؛ دیگران تا پایان پنجره نمی‌توانند بخرند |
| 13 | گزارش مدیر | محبوب‌ترین کالاها، پرتقاضاترین سایز/رنگ (کل فروشگاه یا هر محصول)، تعداد منتظران |
| 14 | اعلان خودکار هنگام ورود موجودی | گوش دادن به تغییر موجودی/قیمت (CRUD، تغییر مستقیم متا، ایمپورت) + صف Action Scheduler |
| 15 | قوانین ترکیبی | رنگ + سایز + قیمت کمتر از X + موجودی بیشتر از Y، همه با هم (AND) یا هر شرط جداگانه |

Flowهای ۱ تا ۶ PRD هم دقیقاً به همین ترتیب پیاده شده‌اند: ثبت درخواست ← ذخیره ← تشخیص تغییر ← بررسی ویژگی‌ها و شرایط ← ساخت پیام ← ارسال از کانال انتخابی ← ثبت وضعیت ← نمایش در گزارش.

## قابلیت‌های پیشرفته اضافه (فراتر از PRD)

- **ارسال موجی منصفانه**: با موجودی کم، ابتدا (موجودی × ضریب) نفر اول به ترتیب ثبت مطلع می‌شوند؛ اگر کالا هنوز موجود بود موج بعدی بعد از فاصله تعیین‌شده — جلوی «۳۰۰ پیامک برای ۲ عدد کالا» را می‌گیرد.
- **ردیابی کلیک و خرید (ROI)**: لینک کوتاه ردیابی در پیام، نسبت‌دادن سفارش به اعلان (با موبایل/ایمیل/کاربر) و نمایش نرخ کلیک، نرخ تبدیل و **درآمد حاصل از اعلان‌ها** در داشبورد.
- **اولویت تامین موجودی**: لیست کالاهای ناموجود به ترتیب تقاضا همراه با «درآمد بالقوه در صورت تامین».
- **تایید شماره/ایمیل با کد یکبار مصرف (OTP)** برای مهمان‌ها یا همه — جلوی ثبت شماره دیگران و هدررفت پیامک را می‌گیرد.
- **ضد اسپم**: Honeypot، محدودیت درخواست برای هر IP، سقف درخواست فعال برای هر شماره/ایمیل.
- **اثبات اجتماعی**: «۳۲۰ نفر منتظر این کالا هستند» (با حداقل قابل تنظیم و به تفکیک تنوع).
- **پنل مدیر**: داشبورد KPI، لیست درخواست‌ها با فیلتر/جستجو/عملیات گروهی و خروجی CSV (سازگار با اکسل)، لاگ ارسال با «ارسال مجدد» پیام‌های ناموفق، متاباکس منتظران در صفحه ویرایش محصول + ستون 🔔 در لیست محصولات، دکمه «بررسی و ارسال اکنون».
- **قالب پیام قابل ویرایش** برای هر رویداد (پیامک/ایمیل/عنوان) با متغیرها.
- **پیامک پترن/خدماتی** برای همه درگاه‌ها (مناسب خطوط خدماتی و ارسال به لیست سیاه).
- **وب‌هوک خروجی** برای n8n / Zapier / CRM پس از هر ثبت درخواست و هر ارسال.
- **انقضای خودکار درخواست‌ها**، پاکسازی لاگ، بررسی ایمنی روزانه برای تغییراتی که خارج از ووکامرس انجام شده‌اند.
- **حریم خصوصی (GDPR)**: خروجی و حذف داده شخصی از ابزارهای وردپرس.
- اتصال درخواست‌های مهمان به حساب کاربری پس از ورود.

## شورت‌کدها

| شورت‌کد | توضیح |
|---|---|
| `[khabar]` / `[khabar product_id="123"]` | دکمه و فرم خبرم کن |
| `[khabar_my_alerts]` | پنل «خبرم کن‌های من» |
| `[khabar_bell]` | زنگوله اعلان‌های داخل سایت |

## متغیرهای قالب پیام

`{customer_name}` `{product_name}` `{variation}` `{price}` `{old_price}` `{regular_price}` `{target_price}` `{stock}` `{link}` `{site_name}` `{minutes}` `{exclusive_note}` `{manage_link}` `{code}`

## هوک‌ها برای توسعه‌دهندگان

| هوک | نوع | توضیح |
|---|---|---|
| `khabar_subscription_created` | action | `( $id, $row )` |
| `khabar_notified` | action | `( $sub, $event, $product, $results )` |
| `khabar_clicked` / `khabar_converted` | action | کلیک روی لینک / ثبت خرید |
| `khabar_message_vars` | filter | تغییر/افزودن متغیرهای پیام |
| `khabar_pre_send_sms` | filter | جایگزینی کامل ارسال پیامک (مقدار غیر null برگردانید) |
| `khabar_send_channel_{name}` | filter | افزودن کانال سفارشی (مثلاً تلگرام/بله) |
| `khabar_settings_schema` | filter | افزودن فیلد تنظیمات |
| `khabar_supports_product` | filter | فعال‌سازی برای انواع دیگر محصول |

REST API: `khabar/v1/subscribe`، `verify`، `subscriptions`، `subscriptions/{id}`، `notifications`، `push/subscribe`، `push/latest`.

```

includes/
  class-khabar-watcher.php        تشخیص تغییر موجودی/قیمت ← صف
  class-khabar-dispatcher.php     ارزیابی منتظران هر محصول و ارسال
  class-khabar-rules.php          موتور قوانین (AND شرایط، تطبیق ویژگی‌ها)
  class-khabar-waves.php          ارسال موجی
  class-khabar-reservation.php    پنجره خرید اختصاصی
  class-khabar-channels.php       رجیستری کانال‌ها، ساخت پیام، لاگ
  channels/                       ایمیل، پیامک، واتساپ، داخل سایت
  class-khabar-push.php           Web Push (VAPID، بدون payload)
  class-khabar-rest.php           REST API فرانت
  class-khabar-frontend.php       دکمه/فرم صفحه محصول (کلاسیک + بلوکی)
  class-khabar-account.php        خبرم کن‌های من
  class-khabar-tracking.php       کلیک و خرید
  admin/                          داشبورد، درخواست‌ها، گزارش‌ها، لاگ، تنظیمات
templates/                        قالب‌های قابل بازنویسی
assets/                           JS/CSS و Service Worker
tests/integration.php             تست یکپارچه سراسری
```

## اجرای تست

روی یک نصب وردپرس + ووکامرس (ارسال‌ها شبیه‌سازی می‌شوند و چیزی واقعاً ارسال نمی‌شود):

```bash
wp eval-file wp-content/plugins/khabar/tests/integration.php
```

این تست ۷۷ سناریو را بررسی می‌کند: همه Flowها و قابلیت‌های ۱ تا ۱۵، OTP، پنل کاربر، امضای VAPID، ارسال موجی، رزرو اختصاصی، ردیابی خرید و رندر صفحات مدیریت.

## پیشنهادهای نسخه‌های بعدی

- کانال **تلگرام / بله / ایتا** با اتصال حساب از طریق ربات (هوک `khabar_send_channel_*` آماده است).
- **پیش‌بینی تقاضا و پیشنهاد مقدار سفارش خرید** به تامین‌کننده بر اساس تعداد منتظران و نرخ تبدیل تاریخی.
- **نمودار تاریخچه قیمت** در صفحه محصول و پیشنهاد «بهترین زمان خرید».
- **ویجت المنتور و بلوک گوتنبرگ** اختصاصی.
- **پیشنهاد محصول جایگزین** به منتظران وقتی کالا مدت طولانی ناموجود می‌ماند.
- **کد تخفیف اختصاصی خودکار** در پیام موجود شدن برای افزایش نرخ تبدیل.
- **A/B تست قالب پیام‌ها** و گزارش نرخ تبدیل هر قالب.
